## Cloud Computing Concepts
- What is cloud computing? cloud computing is the delivery of computing servers databases and software over the internet it allows users to access resources without having to manage all the physical hardware themselve
- One possible benefit:cloud computing provides easy access to files and application from different location as long as an internet connection is available
- One possible risk or limitation:cloud computing depends on an internet connection and security or privacy risk may occur if data is not properly connected
- Difference between uploading code and deploying an application: uploading codemeans transferring source files to a repository or cloudcomputing for storage andcollaboration
## Commands Practiced
List at least four commands and explain each briefly.pwd – Displays the current working directory.

ls – Lists files and folders in the current directory. On Windows Command Prompt, dir can be used instead.

git status – Shows the current state of the Git repository, including modified and untracked files.

git add . – Stages changes in the current directory for the next commit.

git commit -m "Initial commit" – Saves staged changes in the local Git repository with a descriptive message.

git push – Uploads committed changes to a remote repository, such as GitHub.
